# Interface Hotkey Guard

A RuneLite plugin that suppresses selected hotkeys while selected interfaces are open.

## Settings

Options are grouped into **Interfaces** and **Hotkeys**. Choose Bank, Collection Log, and Settings independently. Select which F1–F12 keys to suppress, and optionally enable **Suppress Esc**. F1–F12 and all three interfaces are enabled by default; Esc suppression is off by default. Only these keys can be configured.

## Development

Requires JDK 17. Run `gradlew.bat run` to launch the developer client or `gradlew.bat jar` to build the plugin JAR.
